📚 **Modern Library**

A cozy personal library web app designed to help you organize your books and track your reading journey.

✨ **Features:**

* 📖 Manage your personal library
* 📚 Currently Reading section
* ✅ Read / Not Read status
* 📊 Reading statistics
* 🔎 Book search
* 📈 Track current pages and reading progress
* 📝 Personal Journal
* 📱 Fully responsive design
* 🎨 Modern cozy library-inspired UI
